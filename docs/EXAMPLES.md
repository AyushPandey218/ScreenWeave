# Examples gallery

The six gallery entries are original synthetic reference designs: rounded login, pricing cards, product detail, dashboard, profile and an illustrated editorial banner. They contain no third-party screenshots or natural photographs. The product and banner graphics are drawn in HTML/CSS/SVG.

Each entry includes its original PNG, a saved layout JSON generated by the actual reconstruction pipeline, and a browser-rendered draft PNG. The gallery labels saved results and imperfections explicitly. Open in editor makes a separate local project from that saved layout; Reconstruct again uploads the reference through the normal workflow. Backend rendering is still needed for preview/export updates in the editor.

The initial snapshots were generated with the reconstruction implementation from commit 406a5e7 on Windows. Font rasterization and future pipeline versions can change fresh results. The gallery is a demonstration, not an independent accuracy benchmark. Difficulty labels indicate anticipated manual editing effort.

## Refresh the generated assets

Run from the repository root with the backend Python dependencies and Microsoft Edge installed. Pass an absolute path to your Playwright package:

```bash
node scripts/generate_gallery.cjs /absolute/path/to/playwright
python scripts/reconstruct_gallery.py
node scripts/render_gallery.cjs /absolute/path/to/playwright
```

The rounded login reference is retained from the original fixtures; the generator creates the other five designs. Inspect each source and draft before committing the images and JSON together. Intermediate HTML files live in ignored reports/gallery.

## Verify

With the frontend and backend running locally:

```bash
node frontend/test-gallery.cjs /absolute/path/to/playwright
```

This covers category filters, reference/draft switching, comparison slider, phone/tablet widths, six separate editable projects, and dismissible first-edit guidance. Guidance is a convenience attached to a newly opened example, not a reconstruction model feature.
